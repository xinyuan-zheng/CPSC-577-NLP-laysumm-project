# Evaluation Scripts

The evaluation scripts are largely from https://github.com/TGoldsack1/BioLaySumm2024-evaluation_scripts for the BioLaySumm 2024 shared task https://biolaysumm.org/.


***
## Setup
Download the AlignScore and LENS models.
```
bash ./get_models.sh
```

Install the other dependencies. 

```
pip install -r requirements.txt
```
